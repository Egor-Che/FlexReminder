# BACKLOG — Гибкие напоминания

Список задач с приоритетами. Обновляется по мере выполнения.

## Принципы приоритизации

1. По сложности — простое вперёд.
2. По важности для пользователя — важное раньше.
3. По количеству переделок — группируем так, чтобы модель данных менялась минимум раз.
4. Учитываем публикацию в RuStore: минимум разрешений, бесплатное приложение.

### ✅ Подволна 1.3 — Цвета и темы (готово)

Реализовано:
- Две темы: **Монохром** (серый) и **Палитра** (цветная). Переключатель в настройках.
- 16 пастельных цветов напоминаний (`ReminderPalette`, каналы RGB в [64; 191]).
- `Reminder.colorIndex: Int?` (миграция v5 → v6).

- Статусные цвета: насыщенные в Палитре, приглушённые в Монохроме.
- Монохром: зебра в списке с переиндексацией при удалении.
- Иконки итераций в карточке — Material (не эмодзи).
- Компонент `IterationStatusLabel` для статусов.

## 🌊 Волна 2 — Свои звуки


**Время:** ~2 вечера.

- [ ] **Выбор звука уведомления**
  - Системные звуки — через RingtoneManager.
  - Свой файл — через SAF (`ACTION_OPEN_DOCUMENT`, тип `audio/*`). **Разрешения не нужны.**
  - Хранить в Reminder: `soundUri: String?` (null = системный по умолчанию).
  - Кастомный звук на уведомление — через новый notification channel с уникальным ID для каждого URI.
  - ВАЖНО: кастомные URI персистентны только через `takePersistableUriPermission`.

**Кастомный звук НЕ переносится между устройствами и НЕ шарится через мессенджеры.**
При импорте/приёме напоминания поле `soundUri` сбрасывается, звук — системный по умолчанию.
Причина: чтобы не запрашивать разрешения на файлы и не раздувать APK/JSON.

## 🌊 Волна 3 — Перенос и шаринг (общий механизм)

**Время:** ~2 вечера.

- [ ] **Экспорт/импорт всех данных**
  - Формат: JSON, расширение **`.flexreminder`** (НЕ `.json` — чтобы Android предлагал только наше приложение, а не сотню разных).
  - MIME-тип: `application/x-flexreminder`.
  - Что переносится: напоминания (все поля кроме `soundUri`), история (опционально галочкой), цвет.
  - Что НЕ переносится: `soundUri` (кастомный звук).
- [ ] **Поделиться напоминанием / применить у другого пользователя**
  - Тот же JSON, отправка через `Intent.ACTION_SEND` в мессенджер.
  - **Intent-filter** в манифесте:
    ```````xml
    <intent-filter>
        <action android:name="android.intent.action.VIEW" />
        <category android:name="android.intent.category.DEFAULT" />
        <category android:name="android.intent.category.BROWSABLE" />
        <data android:scheme="content" />
        <data android:scheme="file" />
        <data android:mimeType="application/x-flexreminder" />
        <data android:host="*" />
        <data android:pathPattern=".*\\.flexreminder" />
    </intent-filter>
При импорте: предпросмотр + кнопка «Сохранить». Данные попадают как обычное напоминание, доступное для редактирования и удаления.

## Разрешения

**Оставляем:**
- `POST_NOTIFICATIONS` (Android 13+) — обязательно.
- `SCHEDULE_EXACT_ALARM` / `USE_EXACT_ALARM` — для точных будильников.
- `RECEIVE_BOOT_COMPLETED` — восстановление после перезагрузки.
- `WAKE_LOCK` — не критично, можно убрать.

**Не нужно (и это преимущество):**
- Интернет, камера, контакты, геолокация.
- `READ_MEDIA_AUDIO` — не нужен, работаем через SAF.
