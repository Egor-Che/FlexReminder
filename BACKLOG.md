# BACKLOG — Гибкие напоминания

Список задач с приоритетами. Обновляется по мере выполнения.

## Принципы приоритизации

1. По сложности — простое вперёд.
2. По важности для пользователя — важное раньше.
3. По количеству переделок — группируем так, чтобы модель данных менялась минимум раз.
4. Учитываем публикацию в RuStore: минимум разрешений, бесплатное приложение.

### ✅ Подволна 1.5 — Ресурсы и локализация (готово)

Реализовано:
- Все пользовательские тексты вынесены в `res/values/strings.xml`.
- Форматы дат и времени — в ресурсах (`format_*`).
- Дни недели — в `string-array calendar_weekdays`.
- Эмодзи вынесены отдельно (`emoji_*`) для возможности замены.
- Единицы измерения — сокращения без `plurals` (`unit_*`).
- Тексты уведомлений и каналов — через `Context.getString(...)`.
- Проверка на отсутствие захардкоженных строк (grep по проекту).
- Задел под смену языка — Issue #21.

**Оценка была:** ~2 сессии. По факту совпало.

**Связанные Issues:**
- #21 — смена языка приложения в настройках (запланировано на Волну 5).

## 🌊 Волна 2 — Перенос и шаринг

**Время:** ~2 сессии.

- [ ] **Экспорт/импорт всех данных**
  - Формат: JSON, расширение **`.flexreminder`**.
  - MIME-тип: `application/x-flexreminder`.
  - Что переносится: напоминания (все поля кроме `soundUri`), история (опционально), цвет.
  - Что НЕ переносится: `soundUri` (кастомный звук).
- [ ] **Поделиться напоминанием / применить у другого пользователя**
  - Тот же JSON, отправка через `Intent.ACTION_SEND`.
  - Intent-filter в манифесте (только наше приложение).
  - При импорте: предпросмотр + кнопка «Сохранить».
  - Данные попадают как обычное напоминание, доступное для редактирования.

## Разрешения

**Оставляем:**
- `POST_NOTIFICATIONS`
