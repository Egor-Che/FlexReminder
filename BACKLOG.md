# BACKLOG — Гибкие напоминания

Список задач с приоритетами. Обновляется по мере выполнения.

## Принципы приоритизации

1. По сложности — простое вперёд.
2. По важности для пользователя — важное раньше.
3. По количеству переделок — группируем так, чтобы модель данных менялась минимум раз.
4. Учитываем публикацию в RuStore: минимум разрешений, бесплатное приложение.

## 🌊 Волна 1 — Статусы, история, цвета (одна миграция БД → v4)

**Время:** 3–4 вечера. Всё делаем сразу, чтобы миграция была одна.

- [ ] **Статус «Выполнено»**
  - Поле `lastCompletedAt: Long?` в Reminder.
  - Кнопка в уведомлении (action), в карточке списка, на экране просмотра.
  - Отметка снимает напоминание с сегодня и фиксирует факт.
- [ ] **Статус «Пропущено»**
  - Поле `lastSkippedAt: Long?` в Reminder.
  - Автоматом: если время срабатывания прошло, а реакции нет в течение N часов.
  - Визуальная метка в списке/просмотре.
- [ ] **История срабатываний**
  - Новая таблица `history` (id, reminderId, plannedAt, firedAt, status, note).
  - Экран «История» с возможностью удаления записей и очистки всей истории.
- [ ] **Цветовая гамма (16 пастельных оттенков)**
  - Enum `ReminderColor` с hex-значениями.
  - Поле `colorIndex: Int` в Reminder.
  - Применяется: светлый тон — фон карточки в списке, тёмный — свитч, акценты, подсветка календаря.
  - Исключаем: чёрный, белый, серый, коричневый.
- [ ] **Улучшение карточки списка**
  - Показ последнего статуса («Выполнено вчера», «Пропущено 2 дня назад»).
  - Быстрые действия прямо в карточке.

## 🌊 Волна 2 — Свои звуки

**Время:** ~2 вечера.

- [ ] **Выбор звука уведомления**
  - Системные звуки — через RingtoneManager.
  - Свой файл — через SAF (`ACTION_OPEN_DOCUMENT`, тип `audio/*`). **Разрешения не нужны.**
  - Хранить в Reminder: `soundUri: String?` (null = системный по умолчанию).
  - Кастомный звук на уведомление — через новый notification channel с уникальным ID для каждого URI (Android так требует).
  - ВАЖНО: кастомные URI персистентны только через `takePersistableUriPermission`.

## Разрешения

**Оставляем:**
- `POST_NOTIFICATIONS` (Android 13+) — обязательно.
- `SCHEDULE_EXACT_ALARM` / `USE_EXACT_ALARM` — для точных будильников.
- `RECEIVE_BOOT_COMPLETED` — восстановление после перезагрузки.
- `WAKE_LOCK` — не критично, можно убрать.

**Не нужно (и это преимущество):**
- Интернет, камера, контакты, геолокация.
- `READ_MEDIA_AUDIO` — не нужен, работаем через SAF.
