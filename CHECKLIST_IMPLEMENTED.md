# CHECKLIST_IMPLEMENTED — Гибкие напоминания

Краткий чек-лист по уже реализованным функциям.
Используется для быстрой регрессии после каждой итерации.

Отметки: ✅ — прошло, ❌ — не прошло, ⚠️ — прошло с замечаниями.

---

- [ ] Пустой список показывает подсказку
- [ ] Карточки отображаются корректно
- [ ] Название, расписание, дата следующего срабатывания видны
- [ ] Тумблер включения работает
- [ ] Иконка звука меняется при клике
- [ ] Иконка звука заблокирована при выключенном событии

- [ ] Плавная прокрутка при большом количестве напоминаний
- [ ] Статус «Период завершён» отображается
