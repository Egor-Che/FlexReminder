## Волна 1 — Статусы, история, цвета

### Статус «Выполнено»
- [ ] Кнопка «Выполнено» появляется в уведомлении
- [ ] Кнопка «Выполнено» появляется в карточке списка
- [ ] Кнопка «Выполнено» появляется на экране просмотра
- [ ] После отметки — визуальное подтверждение
- [ ] В истории фиксируется запись «выполнено»
- [ ] Повторная отметка в тот же день не дублируется
- [ ] Снятие отметки работает (если применимо)

### Статус «Пропущено»
- [ ] Автоматическая отметка через N часов после срабатывания
- [ ] Визуальная метка в карточке
- [ ] В истории фиксируется запись «пропущено»
- [ ] Ручное снятие отметки

### История срабатываний
- [ ] Экран «История» открывается
- [ ] Записи отображаются в обратном хронологическом порядке
- [ ] Фильтр по напоминанию
- [ ] Удаление одной записи
- [ ] Очистка всей истории
- [ ] История не влияет на текущее расписание

### Цветовая палитра
- [ ] 16 цветов доступны
- [ ] Все пастельные, каналы в [64; 191]
- [ ] Нет чёрного, белого, серого, коричневого
- [ ] Выбор цвета сохраняется
- [ ] Цвет применяется к карточке списка (светлый тон)
- [ ] Цвет применяется к свитчам и акцентам (тёмный тон)
- [ ] Цвет применяется к подсветке календаря
- [ ] Смена цвета мгновенно обновляет UI

### Темы (строгая / весёлая)
- [ ] Переключатель тем в настройках
- [ ] Строгая тема — только серые оттенки
- [ ] Весёлая тема — цвета из палитры
- [ ] Выбор темы сохраняется между запусками
- [ ] Тема применяется ко всем экранам
