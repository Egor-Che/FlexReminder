## Волна 1 — Статусы, история, цвета

### Подволна 1.1 — Отметки выполнения

**Точка входа и навигация:**
- [ ] Кнопка «Отметить» есть на карточке напоминания
- [ ] Клик открывает экран «Отметить» для этого напоминания
- [ ] Кнопка «Выполнено» есть в уведомлении
- [ ] Экран центрируется на первой будущей итерации
- [ ] Фон карточки — пастельный цвет напоминания

**Статусы:**
- [ ] COMPLETED — зелёная галочка
- [ ] SKIPPED (USER) — жёлтая иконка
- [ ] SKIPPED (SYSTEM) — красная иконка
- [ ] Статусы взаимоисключающие (нельзя два сразу)
- [ ] Второй тап по той же иконке снимает статус
- [ ] Тап по другой иконке заменяет статус
- [ ] SYSTEM-статус снимается только через постановку USER-статуса
- [ ] Карточка списка показывает 3 итерации со статусами

**Автопропуск:**
- [ ] Через 3 часа после полуночи PENDING → SKIPPED (SYSTEM)
- [ ] Проверка раз в 3 часа через WorkManager
- [ ] Проверка при запуске приложения
- [ ] COMPLETED и SKIPPED (USER) не затрагиваются

**Массовые действия:**
- [ ] «Выполнить всё прошедшее» с диалогом подтверждения
- [ ] Не перезаписывает USER-статусы
- [ ] «Пропустить всё будущее» с диалогом подтверждения
- [ ] До endDate или год вперёд (если endDate нет)
- [ ] Не перезаписывает USER-статусы
- [ ] «Отменить все изменения сессии» работает через snapshot
- [ ] Отменяет только текущую сессию, не задевает прошлые
- [ ] Кнопка неактивна без изменений

**Скролл и производительность:**
- [ ] Скролл вверх (прошлое) и вниз (будущее)
- [ ] Диапазон ±3 года
- [ ] Учёт startDate и endDate
- [ ] Подгрузка по 20 итераций без фризов
- [ ] Тумблер «Показать только с отметками»

**Интеграция:**
- [ ] Отметка заранее блокирует уведомление (не сработает)
- [ ] Снятие отметки возвращает уведомление в план
- [ ] Отметка одной итерации не влияет на другие
- [ ] Работает для напоминаний в режиме «Конкретные даты»
- [ ] Работает для напоминаний с истёкшим endDate (только просмотр)

**БД:**
- [ ] Миграция v3 → v4 прошла без потери данных
- [ ] Записи создаются только при отметке / срабатывании
- [ ] При удалении напоминания связанные итерации удаляются

**Детали:** `TEST_CASES.md` → Модуль 13 (TC-13.1 — TC-13.40)
