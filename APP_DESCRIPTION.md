# APP_DESCRIPTION — Гибкие напоминания

Полное описание приложения для подготовки к публикации и использования
в портфолио QA-специалиста.

---

## Краткое описание

**Гибкие напоминания** — Android-приложение для создания напоминаний
с настраиваемым расписанием. В отличие от стандартных календарей, где можно
задать либо конкретную дату, либо простое повторение (каждый день / неделю /
месяц), приложение позволяет задавать произвольные циклы:

- «N дней подряд включено, M дней перерыв» (2 через 2, 3 через 5, 10 через 20 и т.д.)
- Конкретные даты, произвольно выбранные в календаре, включая разные месяцы

Приложение работает полностью офлайн, не требует интернета и запрашивает
минимум разрешений.

---

## Целевая аудитория

- Пациенты с курсами лечения (приём таблеток по схеме «3 дня пьём — 2 отдыхаем»)
- Люди с регулярными платежами (мобильная связь, ЖКХ, подписки)
- Пользователи с периодическими напоминаниями (спорт, тренировки, уход за растениями)
- Все, кому стандартных календарей недостаточно

## Ключевые возможности (реализовано)

### 1. Создание напоминаний
- Название (обязательное поле)
- Заметка (опциональное поле)
- Дата начала и дата окончания периода
- Время срабатывания (часы и минуты)
- Режим звука: со звуком / беззвучный

### 2. Режим «Интервалы»
- N дней подряд включено, M дней пауза
- Примеры: 1/0 = каждый день, 1/1 = через день, 3/5 = три дня / пять тишины

### 3. Режим «Конкретные даты»
- Множественный выбор дат в календаре
- Клик добавляет или убирает дату
- Сохранение выбора при переключении месяцев

### 4. Синхронизация режимов
- Интервалы → Календарь: генерация дат по текущим интервалам
- Календарь → Интервалы: распознавание простого паттерна

### 5. Уведомления
- Точные будильники
- Кнопки в уведомлении:
  - **Выполнено** — отметить текущую итерацию
  - **Отложить N мин** — отложить (short / long интервалы)
  - **Пропустить** — отметить итерацию пропущенной
- Автоматическое перепланирование после срабатывания
- Отдельные каналы для громких и беззвучных уведомлений
- Восстановление после перезагрузки устройства

### 6. Отметки выполнения (подволна 1.1)
- Три статуса итераций: COMPLETED, SKIPPED (USER), SKIPPED (SYSTEM)
- Автоматический пропуск через N часов после переноса
- Экран «Отметить» с календарём-подсветкой
- Массовые действия: «Выполнить всё прошедшее» / «Пропустить всё будущее»
- Отмена изменений текущей сессии

### 7. Цвета и темы (подволна 1.3)
- **Две темы:** Монохром (серый) и Палитра (цветная)
- **16 пастельных цветов** для напоминаний
- Применение цвета: карточка, свитчи, иконки, календарь
- Единая система темизации Material 3

### 8. Звуки уведомлений (подволна 1.2)
- Встроенная мелодия приложения (по умолчанию)
- Системные звуки (звонки / уведомления / будильники)
- Свой файл через SAF
- Индивидуальный звук для каждого напоминания
- Глобальный звук по умолчанию в настройках

### 9. Архив и история (подволна 1.4)
- Автоматическое перемещение напоминаний с истёкшим endDate
- Экран «Архив напоминаний» с компактными карточками
- Экран «История напоминания»:
  - Просмотр расписания и периода
  - Календарь с подсветкой активных дней
  - Модалка итерации с назначенным/фактическим временем, переносами и статусами
- Создание нового напоминания «по примеру» архивного
- Удаление архивных напоминаний

### 10. Ресурсы и локализация (подволна 1.5)
- Все пользовательские тексты вынесены в `strings.xml`
- Готовность к добавлению других языков
- Форматы дат и времени — в ресурсах

### 11. Приватность и автономность
- Работает полностью офлайн
- Никакого сбора данных, аналитики, рекламы
- Все напоминания хранятся только на устройстве

## Разрешения

**Используются:**
- `POST_NOTIFICATIONS` — показ уведомлений (Android 13+)
- `SCHEDULE_EXACT_ALARM` — точные будильники (Android 12+)
- `USE_EXACT_ALARM` — точные будильники для приложений-будильников
- `RECEIVE_BOOT_COMPLETED` — восстановление расписания после перезагрузки
- `WAKE_LOCK` — пробуждение устройства для срабатывания будильника

**НЕ используются:**
- Интернет, камера, контакты, геолокация, микрофон, файлы

Приложение полностью автономно, никакие данные не покидают устройство.

---

## Уникальные преимущества

1. **Гибкое расписание** — произвольные циклы «N через M», недоступные в стандартных календарях.
2. **Два способа задать расписание** — интервалы и конкретные даты с автопреобразованием.
3. **Минимум разрешений** — нет интернета, нет сбора данных.
4. **Офлайн** — работает без сети.
5. **Простой интерфейс** — без лишних экранов, всё на двух-трёх тапах.
6. **Отложить в один клик** — прямо из уведомления.
