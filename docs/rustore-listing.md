Напоминалка — это приложение для тех, кому мало стандартных календарей.

Обычные напоминалки умеют только простое повторение: каждый день, каждую неделю, раз в месяц. Но реальные задачи так не работают. Курс таблеток — три дня пьём, два отдыхаем. Оплата связи — каждые 30 дней, а не по календарю. Тренировки — два дня занятий, день отдыха. Для всего этого нужно гибкое расписание, а не жёсткие правила.

В «Напоминалке» можно задать любое расписание двумя способами:

• Интервалы. Указываете, сколько дней подряд напоминание работает, и сколько дней пауза. Например, 3 через 5, 2 через 8, 10 через 20 — как угодно.

• Конкретные даты. Отмечаете нужные дни прямо в календаре. Можно переключаться между месяцами, выбирать даты в разнобой, а не подряд.

Дополнительно можно задать период: дату начала и дату окончания. После окончания напоминание перестаёт срабатывать, но остаётся в архиве — с полной историей срабатываний.

ЧТО УМЕЕТ ПРИЛОЖЕНИЕ

• Точные уведомления в заданное время.
• Кнопки прямо в уведомлении: отметить выполненным, отложить на несколько минут, пропустить.
• Гибкая настройка отсрочки: два интервала на выбор — короткий и длинный.
• Настраиваемый звук уведомлений: встроенная мелодия, системные звуки или свой аудиофайл.
• Цветовая настройка: 16 пастельных оттенков для напоминаний, чтобы разделять их по смыслу.
• Две темы оформления: цветная «Палитра» и строгий «Монохром».
• Архив с историей: когда напоминание завершилось, можно посмотреть, когда оно срабатывало, сколько раз откладывалось, что было отмечено.
• Создание нового напоминания по образцу старого — полезно, если нужен новый курс с тем же графиком.
• Восстановление расписания после перезагрузки устройства.

ДЛЯ КОГО ЭТО ПРИЛОЖЕНИЕ

• Для тех, кто принимает лекарства по схеме.
• Для регулярных платежей с периодом не «раз в месяц», а «каждые N дней».
• Для тренировок, процедур, ухода за растениями и животных.
• Для любых других повторяющихся дел с произвольным ритмом.

ПРИВАТНОСТЬ

Приложение работает полностью офлайн. Нет доступа к интернету, нет рекламы, нет аналитики, нет сбора данных. Все напоминания хранятся только на вашем устройстве.

Разрешения запрашиваются минимальные и только те, что нужны для работы будильников и уведомлений. Никакого доступа к камере, контактам, геолокации, микрофону или файлам (кроме выбора аудио для уведомления, и только когда вы сами этого захотите).

«Напоминалка» бесплатная. Если она окажется полезной — буду рад обратной связи и предложениям.
