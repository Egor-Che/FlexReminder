# DESIGN 1.3 — Цвета и темы

Дизайн-документ подволны 1.3: две цветовые схемы, палитра из 16 цветов
для напоминаний, применение цвета ко всем элементам интерфейса.

**Статус:** утверждён
**Дата:** 23.09.2026
**Авторы:** Egor-Che (продуктовые решения), ассистент (технические решения)

---

## Цель

Дать пользователю выбор между двумя визуальными режимами приложения:
строгим (монохромным) и цветным (палитра). В цветном режиме — возможность
присвоить каждому напоминанию свой цвет из фиксированной пастельной палитры.

---

## Терминология

| Термин | Значение |
|---|---|
| **Монохром** | Строгая тема. Только оттенки серого. |
| **Палитра** | Весёлая тема. Использует 16 пастельных цветов. |
| **Цвет напоминания** | Конкретный оттенок, назначенный напоминанию пользователем (только в Палитре). |
| **Статусные цвета** | Зелёный / жёлтый / красный. Используются для отметок COMPLETED / SKIPPED (USER) / SKIPPED (SYSTEM). Присутствуют в обеих темах, в Монохроме — приглушённые. |
| **Зебра** | Чередование светлого и тёмного серого в карточках списка в теме Монохром. |

---

## Две темы

### Монохром

**Философия:** полный отказ от цвета. Пользователь осознанно выбирает
эту тему — значит, цвет ему не нужен.

**Правила:**
- Фон, карточки, кнопки, свитчи, чекбоксы, иконки — **только серые**.
- Никаких цветных акцентов, кроме статусов.
- Свитчи: светлый серый в выключенном состоянии, тёмный серый во включённом.
- Карточки в списке: чередование светлее / темнее (зебра).
- Статусные цвета (✅ ⏭️ ❌) — **приглушённые** (слегка проглядывают
  сквозь серый, как будто «в солнцезащитной тонировке»).
- Цвет напоминания не отображается, опции выбора цвета нет.
- Календарь: подсвеченные даты — тёмный серый.

**Автоматическое присвоение оттенков в списке:**
- Чётные позиции (1, 3, 5...) — светлый серый.
- Нечётные (2, 4, 6...) — тёмный серый.
- При удалении напоминания цвета переиндексируются в соответствии
  с новым порядком.
- Хранение в БД: **не требуется** — цвет вычисляется по позиции в списке
  во время рендеринга.

### Палитра

**Философия:** цветной интерфейс, где каждое напоминание может иметь
свой оттенок — для визуального разделения по смыслу (здоровье, работа,
финансы и т.д.).

**Правила:**
- Каждое напоминание может иметь свой цвет из палитры 16 оттенков.
- По умолчанию — **белый** (нейтральный фон без цветного акцента).
- После того как пользователь выбрал цвет, вернуть белый **нельзя** —
  можно только поменять на другой из палитры.
- Цвет применяется: карточка списка, свитчи, иконки, кнопки, календарь.
- Статусные цвета (✅ ⏭️ ❌) — **не зависят** от цвета напоминания.
  Всегда насыщенные.
- Цвет сохраняется между переключениями тем (см. «Хранение»).

---

## Палитра из 16 цветов

**Требования к оттенкам:**
- Каждый канал RGB в диапазоне **[64; 191]** (отступ ≥25% от краёв 0 и 255).
- Пастельные, ненасыщенные тона.
- Исключены: чёрный, белый, серый, коричневый.
- Расположение — **в порядке спектра** (от красного к фиолетовому,
  как радуга, но в пастельных тонах).

**Раскладка в UI:** 2 строки по 8 скруглённых квадратиков.
Порядок слева направо, сверху вниз — от красного к фиолетовому.

**Ориентировочные цвета (для проверки концепции, точные значения — в коде):**

|---|---|---|
| 1 | Терракотовый | тёплый красноватый |
| 2 | Коралловый | красно-оранжевый |
| 3 | Персиковый | оранжевый |
| 4 | Песочный | жёлто-оранжевый |
| 5 | Пшеничный | жёлтый |
| 6 | Салатовый | жёлто-зелёный |
| 7 | Фисташковый | светло-зелёный |
| 8 | Мятный | зелёный |
| 9 | Бирюзовый | зелёно-голубой |

**Точные hex-значения подбираются в коде** с проверкой каждого канала
в диапазоне [64; 191].

## Правила применения цвета

### В теме Монохром

| Элемент | Цвет |
|---|---|
| Карточка в списке | светлый серый / тёмный серый (зебра по позиции) |
| Свитч «Включено» вкл | тёмный серый |
| Свитч «Включено» выкл | светлый серый |
| Иконки звука | оттенки серого |
| Кнопка «Отметить» | серый фон |
| Подсветка дат в календаре | тёмный серый (на 2–3 тона темнее фона карточки) |
| Фон экрана «Отметить» | светлый серый |
| Статусы ✅ ⏭️ ❌ | приглушённые зелёный / жёлтый / красный |
| Уведомления | системные (не зависят от темы) |

### В теме Палитра

| Элемент | Цвет |
|---|---|
| Карточка в списке | светлый оттенок цвета напоминания (пастельный, α ≈ 0.25) |
| Свитч «Включено» вкл | цвет напоминания (насыщенный) |
| Иконки звука | цвет напоминания |
| Кнопка «Отметить» | цвет напоминания |
| Подсветка дат в календаре | цвет напоминания (тёмный оттенок) |
| Фон экрана «Отметить» | светлый оттенок цвета напоминания |
| Статусы ✅ ⏭️ ❌ | насыщенные зелёный / жёлтый / красный (не зависят от цвета напоминания) |
| Уведомления | системные (не зависят от темы) |

**Важно:** статусные цвета всегда одинаковые и не зависят ни от темы,
ни от цвета напоминания. Это единственный «цвет вне темы».

## Хранение данных

### Цвет напоминания

**Поле в БД:** `Reminder.colorIndex: Int?`

- `null` — белый (не выбран пользователем, только в Палитре).
- `0..15` — индекс в палитре из 16 оттенков.

**Важно:** поле не зависит от активной темы. Если пользователь
выбрал цвет в Палитре, а потом переключился в Монохром и обратно —
цвет сохранился.

**Миграция БД:** версия 5 → 6. Добавление nullable-колонки
`colorIndex INTEGER` с дефолтом NULL.

### Активная тема

**Хранится:** DataStore Preferences (как snooze-интервалы).

**Ключ:** `app_theme` — строка `"MONOCHROME"` или `"PALETTE"`.

**Значение по умолчанию:** `PALETTE`.

## UI-компоненты

### Выбор темы (экран настроек)

Строка «Тема» в настройках. Тап → диалог с двумя опциями:
- **Монохром** — описание «Только серые оттенки»
- **Палитра** — описание «16 пастельных цветов для напоминаний»

Выбор — радиокнопки. Применяется сразу после нажатия «Сохранить».

### Выбор цвета (редактор напоминания)

**Расположение:** внизу экрана редактора, после секции «Время».

**Заголовок секции:** «Цвет».

**Внешний вид:**
- 2 строки по 8 скруглённых квадратиков (56×56 dp, радиус скругления 12 dp).
- Порядок слева направо, сверху вниз — по спектру.
- Между квадратиками — отступ 8 dp.
- Активный цвет обведён толстой рамкой (3 dp) + галочка внутри.
- Белый (дефолт) — не отображается в палитре как отдельный элемент;
  если цвет не выбран, ни один квадратик не активен.

**Поведение:**
- Тап по квадратику → он становится активным.
- Возврат к белому невозможен — после выбора всегда остаётся
  хотя бы один активный цвет.
- Изменения применяются по кнопке «Сохранить».

**В теме Монохром секция «Цвет» не отображается вообще.**

## Поведение при переключении тем

### Палитра → Монохром

- Цвета напоминаний остаются в БД, но не отображаются.
- Список использует зебру.
- Все элементы становятся серыми (кроме статусов).

### Монохром → Палитра

- Каждое напоминание возвращает свой ранее выбранный цвет.
- Если у напоминания `colorIndex = null` — карточка белая.

**Никаких диалогов подтверждения при переключении.**
Тема меняется сразу.

---

## Тёмная тема системы

**В v1.3 не поддерживается.** Приложение всегда работает в светлой теме,
независимо от системной настройки.

**В будущем (не сейчас):** можно автоматически применять Монохром,
когда система переходит в тёмный режим. Это архитектурно возможно,
но не входит в текущую подволну.

## Открытые вопросы

1. **Что показывать в палитре в теме Монохром?**
   Решено: секция скрыта целиком. Никаких подсказок.

2. **Что если пользователь выбрал цвет, потом переключился в Монохром,
   потом удалил напоминание, потом создал новое?**
   Новое получит `colorIndex = null` (белый).

3. **Как быть с карточкой в теме Палитра у напоминания с `colorIndex = null`?**
   Фон — стандартный Material (surface). Никакого пастельного оттенка.
   При этом свитчи и иконки используют системный цвет (синий).

4. **Цвет иконок статусов в Монохроме — какая именно приглушённость?**
   Ориентир: смешать насыщенный цвет с серым ≈ 50/50.
   Точные hex подбираются при реализации.

## Что НЕ входит в эту подволну

- Тёмная тема системы.
- Color picker (пользовательские оттенки вне 16 предустановленных).
- Градиенты, тени, анимации при смене темы.
- Настройка цветов для статусов (они всегда фиксированы).
- Темы для конкретных напоминаний (только глобально для приложения).
