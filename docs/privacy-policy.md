# Политика конфиденциальности приложения «Напоминалка»

**Дата последнего обновления:** 26 сентября 2026 г.

## 1. Общие сведения

Настоящая Политика конфиденциальности описывает, какие данные собирает,
хранит и использует мобильное приложение «Напоминалка» (далее — Приложение).

Приложение распространяется бесплатно через магазин приложений RuStore.

## 2. Какие данные собирает Приложение

**Приложение не собирает и не передаёт никакие персональные данные.**

Все данные, которые пользователь вводит в Приложение, хранятся **только на
устройстве пользователя** и не отправляются ни на какие серверы:

- Названия и заметки напоминаний;
- Даты, время и периодичность срабатываний;
- Настройки приложения (тема, звук, интервалы отсрочки);
- История срабатываний;
- Выбранные пользователем звуки уведомлений.

## 3. Разрешения

Приложение запрашивает минимально необходимые разрешения:

| Разрешение | Назначение |
|---|---|
| `POST_NOTIFICATIONS` | Показ напоминаний в виде уведомлений |
| `SCHEDULE_EXACT_ALARM` | Точное срабатывание будильников |
| `USE_EXACT_ALARM` | Точное срабатывание будильников |
| `RECEIVE_BOOT_COMPLETED` | Восстановление расписания после перезагрузки |
| `WAKE_LOCK` | Пробуждение устройства для срабатывания |

Приложение **не запрашивает**:

- Доступ к интернету;
- Доступ к камере;
- Доступ к контактам;
- Доступ к геолокации;
- Доступ к микрофону;
- Доступ к файлам и медиатеке (кроме выбора аудиофайла через системный SAF-диалог по прямому действию пользователя).

## 4. Передача данных третьим лицам

Приложение **не передаёт** никакие данные третьим лицам, поскольку
не имеет доступа к интернету и не взаимодействует с внешними сервисами.

## 5. Сбор аналитики

Приложение **не использует** системы аналитики, рекламы, краш-репортинга
или любые другие сервисы, собирающие данные о пользователе.

## 6. Хранение данных

Все данные хранятся локально в базе данных приложения на устройстве
пользователя. При удалении Приложения все данные удаляются безвозвратно.

## 7. Дети

Приложение не предназначено для сбора данных о детях и не собирает их
(поскольку вообще не собирает никаких данных).

## 8. Изменения политики

Актуальная версия политики всегда доступна по адресу:
[https://Egor-Che.github.io/FlexReminder/privacy-policy.html](https://Egor-Che.github.io/FlexReminder/privacy-policy.html)

При изменении политики дата последнего обновления в начале документа
будет изменена.
